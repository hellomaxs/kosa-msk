# kosa-msk

Посадочная страница с контактами: кнопки, по клику на которые открывается чат
в мессенджере, звонок или почта.

Весь сайт — один файл [`index.html`](index.html). Никакой сборки, зависимостей
и сервера не нужно: откройте файл в браузере или залейте на любой хостинг.

## Что внутри

- **Кнопки связи** — Telegram, WhatsApp (с заранее подставленным текстом
  сообщения), Viber, звонок и почта.
- **Липкая панель снизу на телефоне** — Telegram / WhatsApp / Позвонить всегда
  под большим пальцем.
- Секции: первый экран, услуги с ценами, «запись в три шага», галерея работ,
  частые вопросы, контакты.
- Тёмная тема — подхватывается из системы, плюс переключатель в шапке (выбор
  запоминается).
- Адаптив от 320 px, поддержка `prefers-reduced-motion`, доступность с
  клавиатуры, контраст текста по WCAG AA.
- Разметка Schema.org (`HairSalon`) и Open Graph — для поиска и красивых
  превью в мессенджерах.

## Как поменять контакты

Откройте `index.html` и сделайте поиск с заменой (Ctrl+H / Cmd+H) по всему
файлу:

| Найти | Заменить на | Где используется |
|---|---|---|
| `+79991234567` | ваш номер без пробелов | ссылки `tel:`, WhatsApp, Viber |
| `+7 999 123-45-67` | ваш номер как показывать | подписи под кнопками, подвал |
| `kosa_msk` | ваш ник в Telegram (без `@`) | ссылки `t.me`, подпись |
| `hello@kosa-msk.ru` | ваша почта | кнопка «Почта» |
| `Коса МСК` | название вашего проекта | шапка, заголовки, подвал |

Ненужную кнопку просто удалите — блок `<a class="channel …">…</a>` целиком.
Вёрстка перестроится сама.

Тексты услуг, цен и вопросов правятся прямо в HTML — они лежат в секциях
`#services`, `#how` и `#faq`.

## Как добавить свои фото

В секции `#works` замените заглушки на изображения:

```html
<figure>
  <img src="img/work-1.webp" alt="Афрокосички с канекалоном"
       width="600" height="800" loading="lazy">
</figure>
```

Атрибуты `width` и `height` обязательны — без них страница «прыгает» при
загрузке. Формат лучше WebP, пропорции 3:4.

## Как опубликовать

Подойдёт любой статический хостинг:

- **GitHub Pages** — Settings → Pages → Deploy from a branch, выбрать ветку и
  папку `/ (root)`.
- **Vercel / Netlify / Cloudflare Pages** — подключить репозиторий, сборку не
  указывать, корень проекта оставить по умолчанию.
- **Обычный хостинг** — скопировать `index.html` в корень сайта.

Локально достаточно открыть файл двойным кликом. Если нужен локальный сервер:

```bash
npx http-server . -p 8080
```

## Заметки

- Шрифты Cormorant Garamond и Manrope подключены с Google Fonts. Если они
  недоступны, страница аккуратно откатывается на системные Georgia и
  системный гротеск — вёрстка не ломается.
- Ссылка Viber (`viber://`) работает только на устройстве с установленным
  приложением; на десктопе без Viber браузер её проигнорирует. Поэтому рядом
  всегда есть Telegram, WhatsApp и обычный звонок.
